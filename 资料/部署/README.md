# 部署资料说明

本目录只保存可同步到 Gitee 的安全版本。

未上传/已排除：

- __pycache__/、*.pyc：Python 缓存文件，无需同步。
- raw_logs_*.json：包含访问原始日志和 IP 信息，不上传。
- stats_*.txt：包含访问 IP 明细，不上传。
- stats_*_summary.json：由日志统计生成，如需要可在本地重新生成。
- 月度访问统计报告 docx：可能包含访问统计明细，如需要可在本地重新生成。

已脱敏：

- stats_visit.py：服务器密码已替换为占位符。
- 中烟基本信息(1).txt：密码信息不要明文提交到 Gitee。

如需在新电脑运行统计脚本，请先在本地把密码占位符改为本机私密配置，或改为读取本机环境变量，不要把真实密码提交到 Gitee。
