# 中烟国际集团网站 · 新增新闻标准流程

> 本文档定义向「公司动态」栏目添加一条新新闻的标准流程和强制规则。下次用户给到 .docx 新闻文件时，严格按本手册执行。

---

## 1. 输入

用户给一个 `.docx` 文件（位置通常在 `~/Desktop/`），里面包含：
- **标题**（1 行）
- **日期**（docx 里以「X月Y日」形式出现；默认年份为**当前年**）
- **图片**（1 张或多张；抽取 `word/media/image*.png` 或 `.jpeg`）
- **正文**（多段；按空行/句号切分）

## 2. 编号规则（先盘点，再下手）

读取 `i18n/locales/zh-CN.json` 拿到当前的：
- `newsList` 数组最大 `id` → 新 id = `max_id + 1`
- `message.newsTitle` 最后一个 key 的数字 → 新 `newsTitle<N+1>`
- `message.newsContent` 最后一个 key 的数字 → 新正文从 `newsContent<N+1>` 起，每段 +1

新条目按日期**倒序**插入 `newsList` 头部。

## 3. 必须改的 4 个地方

| # | 文件 | 改什么 |
|---|---|---|
| 1 | `i18n/locales/zh-CN.json` | ① `newsList` 头部插入新条目 `{id, date, title, desc}`<br>② **`newsListIndex` 整体替换**为最新的 3 条（id 22、21、20 这种），永远 3 条<br>③ 新增 `newsTitle<N+1>`<br>④ 新增 `newsContent<N+1> … <N+M>`（每段一个） |
| 2 | `i18n/locales/zh-TW.json` | 同上，繁体用 `「」` 包标题、文段用 OpenCC `s2tw` 转换 |
| 3 | `src/views/newsDetail.vue` | 三个 `v-else-if="id == <新id>"` 分支：<br>① 标题块（`$t('message.newsTitle<N+1>')`）<br>② 日期块（`YYYY-MM-DD`）<br>③ 详情块（`<div class="newspic">` 包图 + `<div class="detailContent">` 引用 `newsContent<N+x>`） |
| 4 | `src/assets/images/newsPic/` | 把图片复制进来，命名 `YYYYMMDD.png` / `YYYYMMDD.jpeg`；同日多图用 `YYYYMMDD_1.png` 序号后缀 |

## 4. ⚠️ 强制规则

### 4.1 标题单行显示（已用 CSS 兜底）

首页卡片 `.news-item-title` 和列表页卡片 `.news-title` 都已经加了：
```css
white-space: nowrap;
overflow: hidden;
text-overflow: ellipsis;
```
超长标题会被 `…` 截断，**不会换行**。

但截断后用户看不到完整标题，**所以：**
- 标题**首选**控制在 **20-25 个汉字**以内，能在卡片完整显示
- 关键信息（人名 / 项目名 / 数字 / 地点）必须保留
- 删修饰语：去掉「正式 / 圆满 / 成功 / 传递温暖力量 / 谱写新篇章」这种形容词
- 详细描述放 `desc` / `content` 字段里，不挤在 title

### 4.2 `newsListIndex` 永远只有 3 条

首页新闻卡片永远只显示 3 条，按日期倒序。每次加新闻：
- 删最旧的一条
- 把新条目插到最前面

**绝对不要**因为加了新条目就变成 4 条。

### 4.3 图片命名 + 路径

- 命名：`YYYYMMDD.png` 或 `YYYYMMDD.jpeg`
- 同日多图：`YYYYMMDD_1.png`、`YYYYMMDD_2.png`…
- 在 `newsDetail.vue` 里 `src` 直接写文件名（相对路径 `../assets/images/newsPic/…`）

### 4.4 日期格式

- JSON 里统一 `YYYY-MM-DD`（例：`2026-06-11`）
- docx 里「6月11日」要推断年份，默认当前年，遇到跨年（比如 12 月的 docx 但当前是 1 月）要确认

### 4.5 简繁对应

- 简体版字段用 `""` 包标题（例：`"中国好人榜"`）
- 繁体版字段用 `「」` 包标题（例：`「中國好人榜」`）
- 繁体用 OpenCC `s2tw` 一次性转换（已 pip 装好 `opencc-python-reimplemented`）
- `newsList.desc` / `newsListIndex.content` 内容用同一份翻译，不留未翻译残留

## 5. 不要改的地方

| 文件 / 位置 | 原因 |
|---|---|
| `i18n/locales/en.json` | 英文版没建 news 字段；`IndexView.vue` 里 `showNews = locale !== 'en'` 会把英文下整块新闻区关掉 |
| `src/views/IndexView.vue` | 数据全从 `i18n.message.newsListIndex` 读，改 i18n 就生效（标题单行 CSS 规则**已在此文件加好**，不要删） |
| `src/views/news.vue` | 数据全从 `i18n.message.newsList` 读，改 i18n 就生效（标题单行 CSS 规则**已在此文件加好**，不要删） |
| `src/components/common/header/Header.vue` | 只引用导航文案 `$t('message.t3')` |
| `src/views/components/SiteSearch.vue` | 同上，搜索模态框里的「新闻资讯」模块名 |
| `src/views/NewView.vue` | 死代码，路由没挂 |
| `src/router/index.js` | `/newsDetail/:id?` 已存在，新 id 自动通 |
