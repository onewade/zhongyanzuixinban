## 新电脑操作提醒

如果在家里电脑使用 Codex：

1. 先拉取 Gitee 仓库。
2. 查看本文件确认环境地址、账号和部署路径。
3. 密码不要写入 Git；需要连接服务器时临时输入，或让 Codex 帮你配置 SSH 密钥免密登录。
4. 部署前先确认当前分支和目标环境：
   - 演示环境：`release`
   - 生产环境：`main`
